      📶 Data sources

        About this data

        RecallRadar aggregates public recall data directly in your browser from openFDA enforcement reports (food, drugs, medical devices), the USDA FSIS recall API (meat, poultry, egg products) and the CPSC recall API (consumer products). Store locations come from OpenStreetMap contributors via the Overpass API.

        This is an informational tool, not an official source. Recall notices name the chains that received recalled lots, but government data does not track store-level inventory — a listed store may never have stocked the recalled lot, and stores not listed may have. Always verify against the linked official notice, and when in doubt, don't consume or use the product. For USDA recalls, store-level retail distribution lists are often published as PDFs linked from the official notice.

        Your location is used only in your browser to query the public APIs above; RecallRadar has no server and stores nothing.
